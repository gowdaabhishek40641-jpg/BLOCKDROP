# BLOCKDROP 🎮

A modern browser-based falling-block puzzle game.

## Features

- HTML5 Canvas
- JavaScript game engine
- Keyboard controls
- Mobile controls
- Score system
- Level system
- Line clearing
- Game-over detection
- Responsive UI

## Controls

← Move Left

→ Move Right

↓ Move Down

↑ Rotate

SPACE - Hard Drop

## Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API
